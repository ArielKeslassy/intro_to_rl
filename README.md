## [cite_start]Part B2 & B3: Training and Evaluating the Imitation Model [cite: 16]

* [cite_start]**Architecture:** We designed a 3-layer fully connected Neural Network with hidden dimensions of `256 -> 128 -> 64`. [cite: 18] [cite_start]The network utilized ReLU activations. [cite: 19]
* [cite_start]**Training Setup:** The model was optimized using the Adam optimizer (learning rate = 1e-3) and Cross-Entropy loss. [cite: 20] [cite_start]The data was split into an 80/20 train/validation ratio, and the data was batched using a batch size of 64 which we found empirically to generalize better. [cite: 21] 
* [cite_start]**Observations:** For too small datasets, the imitation model didn’t have enough information about how to properly navigate the environment, and the models quickly overfitted. [cite: 22] [cite_start]On the larger dataset we can observe generalization. [cite: 23] [cite_start]The 5000 examples imitation model achieved results on par with the expert. [cite: 24]

## [cite_start]Part B5: Few-Shot Imitation Learning [cite: 30]
In this part we were challenged to achieve the minimal passing score (reward=200) with the least amount of data points. [cite_start]To minimize the amount of data required, we experimented with few-shot imitation learning (budget sizes ranging from 2 to 1000 samples) by comparing several data selection strategies: [cite: 31]

### 1. Random Sampling
[cite_start]The standard baseline utilizing a deterministic random seed. [cite: 32]

### 2. Stratified Domain Knowledge
[cite_start]This strategy filters the data to include only transitions from successful episodes (reward ≥ 200) and then balances the core set across: [cite: 33]
* [cite_start]**Actions:** Ensuring all 4 discrete actions are represented. [cite: 34]
* [cite_start]**Spatial Coordinates:** Binning $x$ (horizontal) and $y$ (vertical) positions to ensure the model sees diverse landing and flight scenarios. [cite: 35]

### 3. K-Center Greedy
[cite_start]In this strategy we use the expert's world knowledge and understanding of the task, to search for meaningful data points. [cite: 36] Specifically, we use the expert's latent space, assuming it represents the data points geometrically in a way that encodes their relation to each other and their importance for the task. [cite_start]On this embedding space we perform the K-Center Greedy algorithm: [cite: 37]
1. [cite_start]Pick a random point $c$ and add it to the centers $S$. [cite: 38]
2. [cite_start]For every point $p$ in the dataset, find the nearest center: $c_{min} = d(p,S) = \min_c \{dist(p,c)\}$. [cite: 39]
3. [cite_start]Pick a new point $p$ which is the furthest from $c_{min}$: $p_{far} = \max_p \{d(p,S)\}$. [cite: 40]
4. [cite_start]Add the new point as the next center: $S = S \cup \{p_{far}\}$. [cite: 41]
5. This algorithm outputs $k$ centers that cover most of the data landscape (minimizing the distance of any point to the closest center). [cite_start]We also use the same stratification method from (section B5.2) to balance the samples before applying this method. [cite: 42]

### 4. K-Means
[cite_start]In this algorithm we also search for centers on the expert's embedding space. [cite: 43]
1. [cite_start]Pick a random $k$ points and assign them as centers $S$. [cite: 44]
2. [cite_start]For every point $p$ in the dataset, assign it to the cluster of the nearest center. [cite: 45]
3. [cite_start]For every cluster, compute the new center as the mean of the points assigned to the cluster. [cite: 46]
4. [cite_start]Repeat until convergence. [cite: 47]
5. [cite_start]This algorithm captures the natural data distribution (in the expert's embedding space) and finds clusters that contain similar points w.r.t. the task. [cite: 48] That allows us to use one center instead of many similar data points in that cluster. [cite_start]We also use the same stratification method from (section B5.2) to balance the samples before applying this method. [cite: 49]

### 5. Non-Adaptive GradMatch
[cite_start]GradMatch (Killamsetty et. al, ICML 2021) is a data selection strategy that aims to find a small subset (a coreset) of data whose weighted gradient closely matches the gradient of the entire dataset. [cite: 50] [cite_start]By ensuring the gradient direction of the subset is similar to the full population, the model can theoretically achieve similar training dynamics with significantly fewer samples. [cite: 51]

[cite_start]**Standard GradMatch vs. Our Variant:** [cite: 52]
* [cite_start]**Standard GradMatch:** Typically requires a "warm-start" (training on the full dataset for $R$ epochs) to get the model to a state where its gradients are meaningful, followed by adaptive subset selection during training. [cite: 53]
* [cite_start]**Our Non-Adaptive Variant:** Since our goal is extreme efficiency (Few-Shot), we want to avoid any warm-up on the full dataset. [cite: 54] [cite_start]We achieve this by leveraging the Expert Model as a proxy. [cite: 55] [cite_start]Instead of using the evolving gradients of the model being trained, we calculate the gradients relative to the expert's fixed knowledge. [cite: 56] [cite_start]This allows us to select a high-quality coreset before training ever begins. [cite: 57]

[cite_start]**How it Works:** [cite: 58]
1. [cite_start]We used the same stratification method from (section B5.2) to balance the samples. [cite: 59]
2. [cite_start]**Proxy Gradients:** We pass the data through the expert to calculate the gradients for the final layer. [cite: 60]
3. [cite_start]**Selection:** We use a greedy matching algorithm to find samples whose expert-based gradients best represent the average gradient of the entire expert-collected pool. [cite: 61]
4. [cite_start]**One-Shot Selection:** Unlike standard GradMatch which re-selects data periodically, we select our budget once and train our BC model exclusively on that fixed coreset. [cite: 62]

## [cite_start]Conclusion: Data Quantity vs. Data Quality [cite: 71]
[cite_start]Generally more data (quantity) is better, as confirmed by our Part B4 analysis which showed a direct correlation between dataset volume (up to 10,000 transitions) and generalization. [cite: 72] [cite_start]This is generally because deep neural networks trained with SGD (and its variants) have implicit regularization that promotes generalization and filters noise (*Understanding deep learning requires rethinking generalization*, Zhang et. al, ICLR 2017). [cite: 73] 

[cite_start]However, for extreme cases of data scarcity, we showed that a high-quality, targeted coreset can significantly improve the results and even match those of the models trained on full datasets. [cite: 74]
